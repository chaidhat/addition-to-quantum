# Cases

Cases are like if/else statements for [[variable|variables]].
Let

$$
a(t)=\begin{cases}x_1\quad c_1\\ x_2\quad c_2\\\quad\vdots \\x_n\quad c_n\end{cases}
$$

This means
$a(t)=x_1$ if condition $c_1$ is true
$a(t)=x_2$ if condition $c_2$ is true
so on...

$$
a(t)=x_n\quad \text{s.t.}\quad c_n\text{ is true} 
$$

Also $c_i$ cannot be true whenever $$c_j\quad\forall \quad j\in \{1,...,n\},j\neq i$$
